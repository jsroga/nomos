# World Building Kit

> AI-powered creative writing and world-building platform.

## Overview
A comprehensive toolset for storytellers, game designers, and world builders, powered by a multi-agent AI system.

**Tech Stack:** Next.js 15, Trigger.dev, Supabase, LangGraph.

## Documentation

### Core Modules
*   **[Storyteller](docs/modules/storyteller.md)**: Virtual Writers Room and narrative engine.
*   **[Interior Designer](docs/modules/interior-designer.md)**: 3D world-building and terrain sculpting.
*   **[Loop Creator](docs/modules/loop-creator.md)**: Game loop design and market analysis.
*   **[Chat](docs/modules/chat.md)**: AI chat interface.

### Infrastructure & APIs
*   **[System Architecture](docs/ARCHITECTURE.md)**: Full stack overview, 3rd party services (Vercel, Trigger.dev, etc.), and core patterns.

## Development

See **[CLAUDE.md](CLAUDE.md)** for detailed development workflows and rules.

### Quick Commands
*   `npm run dev` - Start development server
*   `npm run build` - Build for production
*   `npm run mcp:dev` - Start MCP server
*   `npm run test:unit` - Run unit tests
